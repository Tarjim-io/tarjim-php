# Security

## Reporting a vulnerability

Please report security issues **privately to support@tarjim.io**, not in a public GitHub issue or
pull request.

Include what you can of:

- the version of `tarjim/tarjim-php` and of PHP;
- what an attacker can do, and what they need first (a delivery key, control of a server's
  answers, write access to the app's folder);
- the steps or a small script that shows it;
- whether you plan to publish, and when.

Do not include a real key, a signed URL or customer text: describe them instead.

We will acknowledge your report and keep you informed while we fix it. We ask that you give us a
reasonable time to release a fix before you publish.

## Supported versions

Until `1.0.0`, only the latest published version receives security fixes. Today that is the latest
`0.1.0-alpha.N`.
